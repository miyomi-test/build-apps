## 📋 About This Repository

This repository provides pre-built APK files of the **Doki** manga reader app for users who want a ready-to-use version without compiling from source.

### 🎯 What This Repo Provides
- 📱 **Pre-built APK files** - Ready to download and install
- 🔄 **Automatic updates** - Built from the latest public source code
- 🚀 **No compilation required** - Direct installation
- 📚 **Community convenience** - For users who can't build themselves

### ⚠️ Important Disclaimers
- ❌ **Not official** - This is a community build
- ❌ **Not endorsed** - Not affiliated with the Doki development team
- ❌ **No content hosting** - Does not provide any manga content
- ❌ **No affiliation** - Not connected to any publishers or companies

### Installation Steps
1. **Download** the latest APK from the [Releases tab](https://github.com/miyomi-test/build-apps/releases)
2. **Enable** "Install from unknown sources" in Android settings
3. **Install** the APK file
4. **Launch** Doki and enjoy!
